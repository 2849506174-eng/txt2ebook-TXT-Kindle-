========================================
  txt2ebook 使用说明（给新电脑的用户）
========================================

【最简单的用法】

  直接双击  start.bat

  它会自动检查并安装 Python 和 Calibre（需要联网），
  装好后自动启动转换服务。

  然后在浏览器访问：  http://127.0.0.1:8765

  拖入 TXT 文件 → 选格式（MOBI / AZW / AZW3 / EPUB / KFX / TXT）→ 转换 → 下载。


【前提条件】

  - Windows 10 或 11（自带 winget，才能自动安装）
  - 联网（第一次运行要下载 Python 和 Calibre）
  - 首次安装可能需要几分钟


【如果自动安装失败】

  手动装这两个即可，之后再双击 start.bat：

  1. Python 3.13+（装时务必勾选 “Add Python to PATH”）：
     https://www.python.org/downloads/

  2. Calibre（一路下一步）：
     https://calibre-ebook.com/download_windows


【注意】

  - 全程本地运行，文件不会上传到任何外部服务器。
  - 若在旧电脑上安装失败（无 winget），手动装 Python 和 Calibre 后重试即可。
  - KFX 格式需要另外安装 Amazon Kindle Previewer 3（免费，可选）。
  - 除 TXT 外，也支持直接上传 EPUB / MOBI / AZW / AZW3 转换格式（单文件），以及 ZIP / RAR / 7Z 压缩包（ZIP 无需任何额外软件；RAR/7Z 需免费安装 7-Zip）。
  - 成品文件默认存放在程序目录下的 output 文件夹，可在“高级设置”里改成自定义输出目录。
  - 界面语言切换在顶栏 🐱 主题面板底部(中文 / English)；节假日有节日彩蛋。
  - 顶栏 📖 打开阅读器：可读本地小说，自动净化广告、记住进度、支持书签与全屏纯净阅读。
