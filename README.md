# txt2ebook

本地网页工具:把 TXT 文本转换为电子书格式(**MOBI / AZW / AZW3 / EPUB / KFX / TXT**),也支持**从网页小说站点直接抓取目录/章节生成 TXT**。

纯本地运行，文件不上传任何外部服务器；后端调用 Calibre 的 `ebook-convert` 完成转换，服务本身仅用 Python 标准库。

---

## 快速开始

1. 双击 **`start.bat`**
   - 首次运行会自动检测并（通过 winget）安装 Python 和 Calibre，需要联网。
2. 浏览器打开 **http://127.0.0.1:8765**
3. 拖入 TXT → 选格式(MOBI / AZW / AZW3 / EPUB / KFX / TXT)→ 转换 → 下载。

命令行启动（已装好环境时）：

```
python server.py
```

> 详细的新机器安装步骤见 `安装说明.txt`。

## 手机 / 平板访问(同一 WiFi)

默认只在电脑本机打开(127.0.0.1)。想在手机/平板上用:

1. 页面顶栏 🐱 主题面板 → 高级设置 → 勾选「允许手机/平板访问(同一WiFi)」
2. 重启服务(关掉窗口重新双击 start.bat)
3. 顶栏会显示手机访问地址(形如 http://192.168.x.x:8765),点一下即可复制

> 该地址由路由器 DHCP 分配,重启电脑/路由器后可能变化;可在路由器里给本机设静态 IP 固定。
> 转换始终在本机完成,手机只负责上传文件和下载结果,文件不会上传到任何外部服务器。

## 功能特点

- **纯本地运行**:文件不上传任何外部服务器。
- **EPUB 通用格式**:除 Kindle 系列格式外,支持 EPUB,手机/平板/各类阅读器均可用。
- **自定义封面**:可上传自己的图片(JPG / PNG / WEBP)作为封面,不传则自动生成文字封面。
- **可取消转换**:转换中或排队中都可随时取消,不再傻等。
- **任务历史(持久化)**:页面底部展示任务记录(书名/格式/状态/大小),跨重启保留;文件在有效期内可随时重新下载。支持手动清理:仅清记录(保留文件)或记录+文件一并删除。
- **自定义背景**:可上传多张图片或视频作为界面背景并自动取色;图片保存在服务端,主题面板里可点选切换、单张删除或批量删除;支持 GIF 动态图与 MP4/WEBM 视频背景(带背景音乐开关,默认静音);「✕ 取消应用」只是解除应用、不删图。
- **批量队列**:可连续提交多本书,自动排队转换;每条可单独取消,运行中任务在记录里显示实时进度。
- **自动补充分节**:TXT 完全没有章节标题时,每约 1 万字自动插入“第N节”,生成目录并支持拆分。
- **拆分阈值可调**:界面可设置拆分大小(默认 5MB,范围 1-500MB)。
- **KFX 输出(实验性)**:需另装 Amazon Kindle Previewer 3(免费),检测到后可用 KFX 格式。
- **网页小说导入(仅自用)**:左栏「🌐 网页小说导入」粘贴小说**目录页或章节页 URL**,自动抓取正文、去广告/导航,生成干净 TXT 存入本地书库(`library/`),可直接阅读、下载或一键转电子书。抓取走后台任务,有进度、日志、可取消。适配新站 = 往 `sources/` 加一个 JSON 书源,不改代码。详见下方「网页小说导入」章节。
- **阅读模式**:顶栏 📖 按钮打开阅读器,支持打开本地小说(TXT/ZIP,自动净化广告、按章分页)阅读,也支持直接粘贴网页 URL 抓取后阅读;有**阅读记忆**(记住进度,重开自动续读)和**书签**(🔖 加书签、📑 列表跳转),打开页有「最近阅读」可直接续读或删除记录;普通模式带章节栏/字号调节,「⛶ 纯净」切换全屏纯净阅读;阅读器内可切换主题。正文内嵌广告短语也会被清除。转换进行中阅读互不影响。
- **界面主题**:18 套预设配色(深浅均有)一键切换;可上传图片作为背景,自动按图片取色生成整套配色;左栏宽度可拖拽调整(均自动记住)。
- **转换预览**:选完文件自动分析书名/作者/字数/章节数/预计拆分数,书名作者可手动修改后再转。
- **广告清理**:自动删除“请收藏本站”、网址等常见小说网站垃圾行(可开关)。
- **格式互转**:可直接上传 EPUB / MOBI / AZW / AZW3 转换为所选格式(单文件)。
- **压缩包支持**:可直接上传 ZIP / RAR / 7Z,自动解压并识别内部书籍文件。ZIP 用 Python 内置库解压(零依赖);RAR/7Z 需要免费的 7-Zip(绝不依赖 WinRAR 等付费软件),未安装时会明确提示。
- **自定义输出目录**:高级设置里可指定输出文件夹(留空 = 程序目录下 output),新任务的成品文件直接存到该目录,设置保存在 config.json。
- **主题面板**:顶栏 🐱 按钮展开 18 套预设 + 自定义背景图库面板,默认收起不占空间。
- **批量导入文件夹**:把整个文件夹里的每个 TXT 作为一本书,一键批量转换。
- **高级设置**:自定义章节正则、文件保留时长、完成提醒(提示音+系统通知)。
- **多语言界面**:顶栏 🐱 主题面板底部一键切换中文 / English。
- **节日彩蛋**:节假日自动显示节日标识与飘落特效。
- **零第三方依赖**：服务端仅用 Python 标准库（转换依赖 Calibre）。
- **拖拽上传 + 实时进度条**（前端轮询 `/progress/<job_id>`）。
- **多文件合并**：一次选多个 TXT（如 1-100 / 101-200 / 201-300），自动按文件名排序（可拖拽 / ↑↓ 手动调整）合并为一本，自动去除重复的书名 / 作者头。
- **不拆分开关**：可选把合并 / 大文件转成一整本，不按大小自动拆。
- **大文件自动按章节拆分**(>5MB 时):在章节边界断开,逐个转换后打包成一个 ZIP;若无法识别章节则整本转换并在页面提示。
- **中文自动识别**：UTF-8 / GBK 自动识别，统一按 UTF-8 转换。
- **章节识别**：支持 `第X章/节/回/卷`、`Chapter N`，以及 `楔子 / 序 / 序章 / 引子 / 前言 / 番外 / 尾声 / 后记 / 终章` 等无编号标题。

## 网页小说导入(抓取网页小说)

> ⚠️ **仅供自用**。工具不内置任何推广、不做商业用途;抓取内容请自行确认版权合规。

### 用法

1. 点顶栏「📖」打开阅读器,在「🌐 网页小说导入」区粘贴 URL(章节页/目录页均可,自动识别);
2. 选择「书源」(默认自动识别)与「模式」(自动 / 章节页 / 目录页),按需勾选「清理广告」;
3. 点「📥 抓取」:后台任务实时显示进度与日志,可随时「取消」(阅读器不遮住主页,可同时看到转换进度条);
4. 完成后:该书的干净 TXT 已存入**本地书库**(`library/`),面板提供「📖 阅读」「⬇ 下载 TXT」「⚡ 转电子书」三个入口;
5. 「⚡ 转电子书」直接走现有转换流程(封面/拆分/章节识别全部复用),在主页选择顶部格式(MOBI/EPUB/…)即可;
6. 抓取的书籍也会出现在「📖 阅读 → 最近阅读」里,进度/书签照常记忆。

> 阅读器为右侧抽屉(手机端全屏),打开时主页仍可见,可同时操作转换。

### 内置书源

| 书源 | 编码 | 说明 |
|------|------|------|
| 笔趣阁5200 (biquge5200.cc) | GBK | 经典笔趣阁模板,静态页 |
| 笔趣阁5200镜像 (b5200.net) | GBK | 同模板同数据,可作备用 |
| 88笔趣阁 (88biquge.com) | UTF-8 | 目录分页 + 章节分页,自动跟随 |
| 速读谷 (sudugu.org) | UTF-8 | 章节分页(连字符 -2.html)自动跟随 |

### 书源管理(页面内直接添加,无需改文件)

阅读器「🌐 网页小说导入」面板底部有「⚙️ 书源管理」按钮:

- 列出当前书源(内置站不可删,自定义站可删)
- 「➕ 添加书源」表单:书源名称、站点主页、编码、正文容器(tag + id/class)、目录章节正则
- 高级模式:直接粘贴完整 JSON(适合有目录分页/章节分页等复杂配置的站)
- 保存后**立即生效**(写入 sources/<id>.json 并加载),无需改文件或重启
- 书源 id 自动由名称生成;url_re 未填时自动取主页域名

### 书源 JSON 格式(`sources/` 目录)

适配新站 = 在 `sources/` 下新建一个 JSON 文件,无需改代码(启动时自动加载):

```json
{
  "id": "my_site",
  "name": "我的站点 (UTF-8)",
  "home": "https://www.example.com",
  "url_re": "example\\.com",
  "encoding": "utf-8",
  "toc": {
    "link_re": "第\\s*[0-9零一二三四五六七八九十百千两万]+\\s*[章节回卷]",
    "dedupe": "keep_last",
    "pages": { "next_text_re": "下一页|更多章节列表", "max_pages": 30 }
  },
  "chapter": {
    "title": [{"tag": "h1"}],
    "content": [{"tag": "div", "id": "content"}],
    "pagination": true
  }
}
```

- `encoding`: `utf-8` / `gbk`(GBK 会自动按 gb18030 解码)/ 省略 = 自动探测。
- `toc.link_re`:目录页上章节链接文本的正则(默认同左)。
- `toc.dedupe`:`keep_last` 应对「顶部最新章节块 + 全书列表」的站(默认)。
- `toc.pages`:目录分页(如 88笔趣阁 的「下一页/更多章节列表」);没有分页的站可省略。
- `chapter.title` / `chapter.content`:选择器列表,按顺序取第一个命中的元素;`tag` 必填,`id` 精确匹配,`class` 按空格分词匹配。
- `chapter.pagination`:长章节 `xxx.html → xxx_2.html` 自动跟随(如 88笔趣阁)。
- 不写 `url_re` 时该站不会自动匹配,需手动选书源。

### 通用提取(任意网站)

即使没有书源 JSON,粘贴任意**章节页/目录页** URL 也会用通用提取:

1. 优先尝试已安装的 `trafilatura`(可选依赖,`pip install trafilatura` 可装);
2. 未安装则用标准库(HTMLParser + 启发式:最长中文文本块);
3. 正文统一过广告清洗(`_clean_ad_lines`),支持中文/英文章节标题。

页面若是 JS 动态渲染(章节内容由脚本加载)、字体反爬(乱码字形)或图片章节,会明确报错并跳过,不会产出脏数据。目录页超过 `GRAB_MAX_CHAPTERS`(默认 3000)章时会提示并按上限截断;也支持在请求里传 `max_chapters`(界面高级用法)限制抓取章数。

## 大文件如何处理

超大 TXT(几百万字、几千章的合集)在 Kindle 上会很卡,转换也极慢。工具会自动:

1. 检测文件 > 拆分阈值(默认 5MB,可在界面「每本拆分大小」调整,1-500MB);
2. 按大小切分,每部分约等于界面设定的「每本拆分大小」(默认 5MB),**在章节边界处断开,不切半章**;
3. 逐个转换，前端实时显示进度；
4. 全部完成后打包成一个 ZIP 供下载。

可在 `server.py` 顶部调整相关参数（见下方「可调参数」）。

## 格式说明

| 格式 | 说明 |
|------|------|
| MOBI | 旧版 Kindle 通用格式 |
| AZW  | Kindle 早期格式（本质是 MOBI 容器，故按 MOBI 生成后改名 `.azw`） |
| AZW3 | KF8,较新的 Kindle 格式,排版更好 |
| EPUB | 通用格式,手机/平板/各类阅读器均可,排版好 |
| KFX | 亚马逊新版格式,排版最佳;需安装 Kindle Previewer 3(实验性) |
| TXT | 纯文本;电子书可转回 TXT,TXT 输入则输出清洗/分节后的文本 |

> KFX 为 Amazon 闭源格式,依赖官方 Kindle Previewer 3(免费)生成;未安装 Previewer 时界面会禁用该选项。

## 健壮性 / 资源控制

- **流式落盘**:上传不整体读入内存(支持大合集),下载同样分块流式返回。
- **内存占用**:上传/下载为流式,但转换时整本读入内存,数百 MB 的超级大文件建议在内存充足的机器上转。
- **并发限制**：同时转换数受 `MAX_CONCURRENT`（默认 = CPU 核数 / 2）限制，多任务自动排队，避免打满机器。
- **自动清理**:已完成任务及其输出文件在 `JOB_TTL`(默认 6 小时)后清理,最多保留 `MAX_JOBS`(默认 50)个任务;服务启动时还会清扫上次残留的过期目录(如进程被强杀留下的中间文件)。
- **上传上限**：`UPLOAD_MAX_BYTES`（默认 500MB），超过则拒绝。

| 参数 | 默认 | 含义 |
|------|------|------|

| `HEURISTICS_LIMIT` | 1MB | 小于此大小才启用 Calibre heuristics |
| `MAX_CONCURRENT` | CPU 核数/2 | 同时转换的任务数 |
| `JOB_TTL` | 6 小时 | 完成任务保留时长 |
| `MAX_JOBS` | 50 | 最多保留任务数 |
| `UPLOAD_MAX_BYTES` | 500MB | 单次上传上限 |
| `SECTION_CHARS` | 1万字 | 无章节时自动分节的插入间隔 |
| `HISTORY_MAX` / `HISTORY_TTL` | 300 条 / 7 天 | 任务历史持久化的保留上限 |
| `READ_LIB_MAX` | 30 本 | 本地阅读库最多保留的书目(超出自动删最旧) |
| `READ_MAX_TEXT` | 30MB | 阅读单本净化后文本上限 |
| `GRAB_TIMEOUT` | 25s | 抓取单页超时(含 5xx 自动重试) |

| `GRAB_SEM` | 2 | 同时进行的抓取任务数 |

## 工作原理

上传 TXT → 后端调用
`ebook-convert input.txt output.mobi --enable-heuristics`
→ 返回下载链接。

`--enable-heuristics` 让 Calibre 自动识别章节、优化纯文本排版；大文件则改用基于 `CHAPTER_XPATH` 的快速路径按章节切分。

## 目录结构

```
txt2ebook/
├─ server.py        # 服务端：HTTP + 转换逻辑，内置前端页面
├─ start.bat        # 一键启动（自动装 Python/Calibre，仅 Windows）
├─ 安装说明.txt      # 面向新机器用户的安装说明
├─ sources/         # 网页小说书源 JSON(新站 = 加一个 JSON,启动时自动加载)
├─ output/          # 运行时：转换输出
├─ backgrounds/     # 运行时：自定义背景图/视频(backgrounds.json 索引)
├─ library/         # 运行时：阅读本地库(净化后文本,支持续读/书签)
├─ history.json     # 运行时：任务历史持久化（运行时自动生成）
├─ readstate.json   # 运行时：阅读进度与书签
└─ config.json      # 运行时：输出目录、选中背景等设置
```
